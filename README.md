# 게이트웨이 ECU 구현 및 CAN 프로토콜호환 IDS 제작

과거 CAN 프로토콜은 차량 내부 네트워크가 외부와 완전히 단절되어 물리적 접근 없이는 해킹이 불가능했던 신뢰 기반의 환경이었다. 하지만 현재 외부 망과의 접점이 급증하며 원격 공격 표면이 확대되었다.
<br/>
본 연구에서는 차량 내 전자제어 유닛 환경을 모의로 구현하고, 해당 환경에서 악성 메시지 공격을 탐지하는 연구를 크게 두 가지 방향으로 진행하였다.
<br/>
첫째, **게이트웨이 ECU를 구현**하여 차량 네트워크 구간 간의 메시지를 중계하는, 모의 ECU 환경을 구현한다.
<br/>
둘째, **CAN IDS**(Intrusion Detection System)를 구현하여 CAN버스 상의 이상 트래픽 및 공격 패턴을 탐지함으로써 차량 네트워크의 악성 메시지 탐지 가능성을 분석 하였다.

## 📂 파일 구성 및 역할

1.  **`gateway_ecu.py`**
    - 물리 CAN(`can1`)과 가상 CAN(`vcan0/1`) 사이를 연결하는 게이트웨이 ECU 역할을 수행합니다.
    - 네트워크 구간 분리 및 메시지 라우팅 기능을 모사합니다.

2.  **`brake_ecu.py`**
    - 수신단 역할을 하는 하위 ECU(예: 제동 제어기) 시뮬레이터입니다.
    - 게이트웨이를 거쳐 전달된 최종 메시지를 수신하고 상태를 출력합니다.

3.  **`gen.py` (공격 및 트래픽 생성기)**
    - 검증을 위한 트래픽 발생기입니다.
    - `--mode` 옵션을 통해 정상 트래픽뿐만 아니라 세 가지 공격 시나리오(flood, timestamp, dlc)를 선택적으로 생성할 수 있습니다.

4.  **`ids.py` (핵심 산출물)**
    - 차량 침입 탐지 시스템 메인 로직입니다.
    - **탐지 항목:** Flooding(공격성 폭주), Timestamp Anomaly(주기성 변조), DLC Mismatch(데이터 구조 위반)
    - 실시간으로 버스를 모니터링하여 이상 징후 발생 시 경고 로그를 출력합니다.

## 🛠 실행 환경 및 요구 사항

- **Hardware:** Raspberry Pi 4B, MCP2515 기반 CAN HAT
- **OS:** Raspberry Pi OS
- **Language:** Python 3.8+
- **Dependencies:** `python-can`, `SocketCAN` 인터페이스 활성화 필요
